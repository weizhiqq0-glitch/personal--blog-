# 权限、搜索与图片使用

## 站主统一权限
站主登录后，进入「管理后台 → 权限管理」（#/admin/permissions）。管理员和普通用户看不到，也不能直接调用管理接口。
目前可统一控制：阅读文章、阅读评论、发表评论。可以选择一键只读、全部禁用、恢复默认，然后保存。
这些开关适用于所有已验证普通用户；站主、管理员和访客沿用原权限。关闭优先于单个账号的允许设置；恢复默认不会覆盖单个账号的禁用。已有登录会话下一次请求即生效。修改保存在数据库，并留下必要的管理审计记录。

## 搜索
顶部「搜索」、右侧漫游入口、圆盘导航或小猫互动中的「帮我搜索」，进入 #/search。
搜索文章标题、正文、标签，以及项目、照片墙、音乐、说说、碎碎念、友链和关于的标题与描述；同时查找功能页面。文章和板块各最多返回40项，不搜索私密账号、邮箱、反馈或登录记录。中文支持文字匹配，英文忽略大小写。

## 小猫夜间休眠
按当前设备本地时间18:00至次日06:00自动进入休眠。点击小猫或互动菜单中的「叫醒小猫」即可唤醒。当晚在当前标签页内保持唤醒，下一晚重新自动休眠；06:00自动恢复白天状态。主题选择不会改变这个作息。

## 添加图片
头像、全站背景、后台文章正文以及板块封面/照片支持文件选择和电脑拖放；手机会调用系统图片选择器，可从相册选图，不会自动读取整个相册。
支持JPG、PNG、WebP；头像最大8MB，其他入口原图最大10MB，自动压缩。站内内容素材压缩后最多512KB，全站最多200张。照片和封面上传后再保存表单才会展示；已上传素材为公开内容，取消编辑不会删除素材。
头像只需已验证账号；全站背景和内容图片上传限有相应权限的站主/管理员。文章图片以安全的图片标记展示，不执行HTML或脚本。普通用户仍不能编辑照片墙和文章。
图片存储在后端数据库，迁移时需要迁移数据库；只复制GitHub源码不包含图片和账号数据。没有新增付费存储服务。

## GitHub 中文简介
榜单、搜索结果和仓库详情默认显示中文简介，保留「查看原文」。常见项目使用本地中文介绍，其他英文简介通过后端调用公开翻译服务（首选Google，失败后使用MyMemory备用）；机器翻译会标注来源，失败时保留原文并提供重试。只发送公开简介，不发送账号、邮箱或私密内容。项目名称和代码不翻译，README仍保留原始文本。
后端缓存翻译结果30天，限制并发和每日新翻译字符总量4500；免费公共翻译端点没有稳定性保证，不影响原文和其余功能。用户浏览器无需连接Google翻译。
