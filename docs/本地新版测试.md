# 新版页面与本地测试

双击 `tools/本地测试新版.cmd`，随后打开 http://127.0.0.1:5189/ 。关闭该测试窗口即可停止。

此测试使用 `private/local-preview.sqlite`，忽略线上 DATABASE_URL，不会修改线上账号或文章。站主用户名为 mowu；首次启动生成随机测试密码，保存在 `private/本地测试账号.txt`。不要分享这个文件。线上密码不变。测试邮箱仅为占位；该环境不启用真实验证码发送。

## 独立页面

- `#/management`：账号与访问管理，仅具备管理权限者可用。
- `#/settings`：用户设置；主题、用户名与密码。用户名不可重复，修改资料需要当前密码；保存后所有旧会话退出。
- `#/security`：站主登录报备。先登录站主，再输入当前密码，将常用浏览器绑定为唯一报备查看设备。
- `#/experience`：彩色光标围绕指针旋转，加载完成后逐项框选并打字显示；支持重播、跳过、减少动画。手机默认围绕展示区域中心。文章为空时使用明确的示例文字。
- `#/daily`、`#/playground`：新闻与游乐场已从首页拆分。

后续新增功能采用独立的 URL 页面，保留首页入口。Hash 路由兼容静态托管，刷新和浏览器前进后退均可用；独立页面不代表每次都弹出浏览器新标签。

## 登录报备的边界

从绑定设备后开始，仅记录其他浏览器**成功登录站主账号**的时间和浏览器/系统，不采集 IP 或定位。站主登录后，在绑定浏览器打开报备页可查看；每30秒刷新，有新记录会在站内显示提醒，服务器保留90天，最多返回100条。失败登录由现有登录限流处理。

后端同时核验站主会话与256位随机设备凭证，数据库只存凭证哈希；其他设备即使登录站主也不能读取报备。设备是浏览器凭证，不是硬件身份证；复制浏览器数据或失窃凭证可能冒充设备。清除网站数据、更换浏览器、无痕窗口会失去设备权限。

本地测试服务允许回环连接验证站主密码后绑定。线上首次绑定需要站主密码以及独立的本机绑定授权码；授权码只保存在本机 private/设备绑定授权码.txt，Cloudflare 仅保存其 SHA-256 摘要。绑定后不允许通过其他浏览器替换，即使知道授权码也不能替换。恢复本地绑定：停止测试服务，用 SQLite 管理工具删除测试库 `owner_trusted_device` 表对应记录，再重新启动绑定；不要删除整个数据库。线上丢失设备凭证时，需要通过数据库管理权限离线恢复；不提供绕过设备校验的网页恢复接口。

测试前旧版代码已生成 ZIP，位于 `private/version-backups`，自动最多保留3份。private、数据库、密码文件均受 .gitignore 排除。用户已授权发布新版。线上站主用户名一次性迁移为 mowu，密码、邮箱和账号ID不变；迁移记录保存在数据库，今后用户自行修改用户名不会被覆盖。

首次进入网站会展示彩色光标加载动画，完成后实际首页内容逐段浮现。动效体验页提供逐字输入演示，可重播与跳过。“减少动画”遵循系统偏好并在当前浏览器保存。
