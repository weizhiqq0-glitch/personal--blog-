# 注册连接故障与免费入口

2026-11-07 排查发现：当前电脑直连原 workers.dev 接口超时，使用代理正常；Pages 免费入口直连正常。这是局部网络测试，不能保证所有运营商都可访问。

当前请求路径：GitHub Pages 前端 → https://mowu-blog-api-gateway.pages.dev/api/… → Cloudflare 内部服务绑定 personal-blog-api → 原数据库。没有复制账号或创建第二个数据库；密码校验、验证码、防刷、站主设备绑定仍由原后端处理。

`gateway/public/_worker.js` 只转发 `/api/` 给固定服务，不能传入任意目标网址。网关不含密码或数据库密钥。Pages Functions 与绑定 Worker 均受平台免费额度限制，不承诺无限用量或国内网络可用性。

前端部署工作流使用 GitHub 仓库变量 `VITE_API_GATEWAY_URL`，未设置时使用上述已验证的 Pages 地址。以后换接口域名，修改该变量并重新运行 Deploy blog to GitHub Pages。旧 `VITE_API_URL` 变量暂不用于 Pages 构建，避免重新指向不可达的旧入口。

更新网关（在 gateway 目录）：

```powershell
node ../backend/node_modules/wrangler/bin/wrangler.js pages deploy public --project-name mowu-blog-api-gateway --branch main
```

前端连接失败时有超时提示与“重新连接”按钮；只读请求在网络异常时最多自动重试一次。注册、登录、验证码等写请求不自动重放，避免重复发送邮件或重复提交。若提交后断网，先检查邮箱或尝试登录，确认结果后再操作。

排查顺序：打开上述入口的 `/api/health`；若打不开，切换 Wi-Fi/移动网络对比；若持续不可达，需要换入口或部署地区。不要把数据库地址、密码或验证码放进网址、仓库或故障截图。
