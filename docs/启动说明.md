# 本地启动

双击项目根目录“博客工具.cmd”，选择1，或进入tools双击“启动博客.cmd”。启动器打开前后端两个终端并打开网页；关闭对应终端停止服务。

首次运行先安装Node.js 24 LTS，在根目录执行 npm --prefix backend ci 与 npm --prefix frontend ci。账号、邮件与额度初始化按根目录README说明操作。

本地网站：http://127.0.0.1:5173/ 。本地数据库留在backend/data，不会自动与线上Neon同步。

工具均按相对路径工作。不要移动单独的scripts或tools；搬家复制整个personal-blog。原有.lnk快捷方式已经清理，避免继续指向旧入口。
