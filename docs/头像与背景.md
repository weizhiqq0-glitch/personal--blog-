# 头像与背景

右侧“用户设置”始终保留。登录后在该页选择 JPG、PNG 或 WebP 头像（最多8MB），预览后点击保存。浏览器居中裁切并转成最多256×256的PNG，后端限制96KB；头像存入数据库，可跨设备随账号显示。头像属于公开资料，显示在账号、站主资料卡和评论旁；恢复默认头像会删除原头像。

背景入口：用户设置 → 背景设置。支持10MB以内图片和40MB以内MP4/WebM视频，静音循环播放。文件只存在当前浏览器的 IndexedDB，按登录账号或访客分别保存，不上传GitHub或服务器。清除网站数据或换设备需要重新选择。切换标签页时视频暂停，系统减少动态效果时不自动播放。

Wallpaper Engine 与 Steam 创意工坊不是网页壁纸接口。网站无法直接访问本机 Steam 订阅库，也不能运行 Wallpaper Engine 的场景、应用壁纸或 .pkg。若订阅的是视频类型，可在 Wallpaper Engine 中找到该壁纸的本地文件夹，选用其中可播放的 MP4/WebM；图片类型选用图片。场景型需另行制作成视频，并遵守素材授权。把创意工坊分享链接粘贴进网站不会成为动态背景。

手机版不显示或运行彩色鼠标环绕加载动画。桌面有鼠标、允许动态效果时，仍保留朝向主鼠标的小范围随机游动。

外观参考 YuJing（https://www.yujingblog.top/2/）的纸张侧栏，以及 paeardog（https://www.paeardog.top/）的柔和卡片布局。本次样式为项目内重新实现，没有复制对方文章、头像、音乐或壁纸资源。保留本项目看板猫、文章和所有既有板块，并新增文章归档与标签筛选页面。
