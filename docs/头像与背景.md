# 头像与背景

右侧“用户设置”始终保留。登录后在该页选择 JPG、PNG 或 WebP 头像（最多8MB），预览后点击保存。浏览器居中裁切并转成最多256×256的PNG，后端限制96KB；头像存入数据库，可跨设备随账号显示。头像属于公开资料，显示在账号、站主资料卡和评论旁；恢复默认头像会删除原头像。

背景入口：管理后台 → 全站背景（`#/admin/appearance`）。仅已验证的站主与管理员可以进入后台；背景修改另需“管理扩展板块内容”权限，站主可限制管理员。背景统一发布给所有访客，不再提供个人壁纸设置。旧浏览器中的个人壁纸不再读取。

支持上传10MB以内 JPG/PNG/WebP，由浏览器压缩到1920边长以内、512KB以内保存到本站数据库；或填写公开 HTTPS 图片直链、MP4/WebM视频直链。视频只使用直链，不直接上传大视频到数据库；文件需先托管。使用外站链接时，访客浏览器将向该地址请求媒体。动态视频静音循环，切到后台暂停；系统减少动态效果时不自动播放。其他访客刷新或最多约一分钟可看到新背景。

Wallpaper Engine 与 Steam 创意工坊不是网页壁纸接口。网站无法直接访问本机 Steam 订阅库，也不能运行 Wallpaper Engine 的场景、应用壁纸或 .pkg。若订阅的是视频类型，可在 Wallpaper Engine 中找到该壁纸的本地文件夹，选用其中可播放的 MP4/WebM；图片类型在后台上传；视频类型先托管为公开HTTPS直链，再在后台填写。场景型需另行制作成视频，并遵守素材授权。把创意工坊分享链接粘贴进网站不会成为动态背景。

手机版不显示或运行彩色鼠标环绕加载动画。桌面有鼠标、允许动态效果时，仍保留朝向主鼠标的小范围随机游动。

外观参考 YuJing（https://www.yujingblog.top/2/）的纸张侧栏，以及 paeardog（https://www.paeardog.top/）的柔和卡片布局。本次样式为项目内重新实现，没有复制对方文章、头像、音乐或壁纸资源。保留本项目看板猫、文章和所有既有板块，并新增文章归档与标签筛选页面。

首页个人卡片固定关联站主账号的公开头像。站主本人保存头像后立即更新，其他前台页面每30秒检查一次头像版本，切回窗口时也会检查；站主恢复默认头像后，卡片回到名字首字。公开资料只新增头像版本号，不包含邮箱、密码或设备信息。
浏览器标签页使用 frontend/public/favicon.svg 中的鼠尾草绿星形图标。
